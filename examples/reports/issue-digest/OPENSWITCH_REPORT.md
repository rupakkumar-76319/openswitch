## How each model was chosen
Every function was run on 6 Nemotron configs with 12 inputs generated from its own real prompts (captured by running the app's code against a fake SDK). Each output was fed back through the app's own post-processing (functional check) and checked by Nemotron 3 Ultra against a pass/fail checklist (correctness plus the call's rubric); score = share of checks passed. Every config is graded, the strongest one included. The cheapest config with 100% functional outputs, a mean within 0.75 of the best config (and ≥ 7.5) and no output below 5.0 was chosen.
