  • For Nebius Token Factory, the base URL is "https://api.studio.nebius.com/v1/" and authentication uses a Bearer token in the Authorization header with the NEBIUS_API_KEY environment variable. · source
  • Supported parameters in the OpenAI-compatible API include max_tokens, temperature, top_p, top_k, n, stream, stream_options, stop, presence_penalty, frequency_penalty, logit_bias, logprobs, top_logprobs, user, extra_body, and response_format. · source
  • JSON output can be enabled via response_format={"type": "json_object"} or response_format={"type": "json_schema", "json_schema": <schema>} for structured outputs like Pydantic models. · source
  • Nemotron thinking (reasoning) can be controlled via extra_body.chat_template_kwargs with enable_thinking:true/false and reasoning_budget:<integer> parameters, as seen in NVIDIA Nemotron models and Ollama compatibility layers. · source
  • Anthropic-only parameters like max_tokens map directly to the OpenAI-compatible API's max_tokens field when using protocol conversion gateways (e.g., API7 AI Gateway or CompactifAI). · source
  • The model parameter must specify the full model identifier (e.g., "meta-llama/Meta-Llama-3.1-70B-Instruct", "Qwen/Qwen3-235B-A22B") as shown in working examples. · source
  • Streaming is supported via stream=true and stream_options can be set to null or omitted; SSE chunks are compatible with OpenAI-style streaming. · source
  • Parameters such as reasoning_effort (used in OpenAI o3-mini) are not mentioned as supported in the Nebius Token Factory or NVIDIA Nemotron documentation within the provided results and should not be assumed available. · source
