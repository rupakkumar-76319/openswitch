  • Endpoint: baseURL/base_url must be set to "https://api.studio.nebius.com/v1/". · source
  • Authentication: Use Authorization header with Bearer token from NEBIUS_API_KEY environment variable. · source
  • Supported parameters: max_tokens, temperature, top_p, top_k, n, stream, stream_options, stop, presence_penalty, frequency_penalty, logit_bias, logprobs, top_logprobs, user, response_format, extra_body. · source
  • Unsupported parameters: Anthropic-specific parameters like thinking, output_config.effort, cache_control, tool.eager_input_streaming, service_tier, speed, context_management, fallbacks, diagnostics are not carried over and may cause 400 errors if passed. · source
  • JSON output: Use response_format={"type": "json_object"} for unconstrained JSON or {"type": "json_schema", "json_schema": <schema>} for schema-constrained JSON via Pydantic or direct JSON Schema. · source
  • Enable/disable Nemotron thinking: Pass chat_template_kwargs in extra_body with {"enable_thinking": true} to enable or {"enable_thinking": false} to disable thinking mode. · source
  • For Nemotron models with disabled thinking, also set force_nonempty_content: true in chat_template_kwargs to avoid empty responses due to reasoning parser issues. · source
  • Anthropic-only parameters mapping: When using Anthropic SDK with OpenAI-compatible backend via gateway, system_prompt maps to system role message, max_tokens maps to max_tokens, messages maps directly, stream maps to stream, but Anthropic-specific fields like thinking, output_config.effort, cache_control are ignored or refused. · source
