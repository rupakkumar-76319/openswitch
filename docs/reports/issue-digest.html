Sources (live Tavily research)

  • gpt-4o: $2.5 / $10.0 per 1M · https://pricepertoken.com/pricing-page/model/openai-gpt-4o
  • Endpoint URL is https://api.studio.nebius.com/v1/ · source
  • Authentication uses Authorization: Bearer <NEBIUS_API_KEY> · source
  • Supported parameters include max_tokens, temperature, top_p, top_k, n, stream, stream_options, stop, presence_penalty, frequency_penalty, logit_bias, logprobs, top_logprobs, user, and extra_body · source
  • JSON output can be enabled via response_format: { type: "json_object" } or response_format: { type: "json_schema", json_schema: <schema> } · source
  • Nemotron thinking can be disabled by setting extra_body.chat_template_kwargs.enable_thinking: false · source
  • For Nemotron models, when enable_thinking is false, force_nonempty_content may be needed to avoid empty content due to parser behavior · source
  • Anthropic-specific parameters like thinking are not supported; use chat_template_kwargs instead for reasoning control · source
  • The OpenAI-compatible API forwards chat_template_kwargs to vLLM for Nemotron models when properly configured · source
